🏗️ Arquitectura del Sistema

⚡ SynapseBus

Bus asíncrono Pub/Sub en memoria para comunicación Agent-to-Agent en tiempo real vía WebSockets.

🧠 LiveAgent + LiteLLM

Agentes autónomos que escuchan el bus, procesan mensajes vía LLM (OpenAI/Anthropic/Groq) y responden.

🗄️ SQLite WAL

Motor de almacenamiento con journal WAL, PRAGMAs optimizados, e índices para 10k ops/sec.

🔐 JWT + Rate Limiter

Autenticación stateless con tokens JWT, rate limiting por agente, y validación Pydantic estricta.

📊 Prometheus + Grafana

Stack de observabilidad completo con métricas exportadas y dashboards de telemetría visual.

🐳 Docker Multi-Stage

Imagen de producción ultra-ligera, usuario non-root, HEALTHCHECK nativo, lista para Kubernetes.
